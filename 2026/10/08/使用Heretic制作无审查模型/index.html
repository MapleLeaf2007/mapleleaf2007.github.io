Heretic 是什么

README 第一段已经说明工具用途:

Heretic is a tool that removes censorship (aka “safety alignment”) from transformer-based language models without expensive post-training. It combines an advanced implementation of directional ablation, also known as “abliteration” […], with a TPE-based parameter optimizer powered by Optuna.

这是合法、公开的开源项目,基于 Arditi et al. 2024 提出的 directional abliteration 论文,通过 Optuna 的 TPE 贝叶斯优化自动寻找最优消融参数(无需人工调参)。它生成的是 LoRA adapter 或者合并后的完整模型,作为 Hugging Face 格式(safetensors)输出。

格式问题

平常下载/运行的模型格式为 GGUF 格式，类似于：

这是 GGUF 格式 (llama.cpp专用)。但 Heretic 内部依赖 Hugging Face Transformers,通过 AutoModelForCausalLM / AutoModelForVision2Seq 加载模型,只接受 safetensors/checkpoint 的 Hugging Face 仓库结构(有 config.json + tokenizer.json + *.safetensors)。

heretic --help 也写得很清楚:

GGUF 必须通过 llama-cpp-python 才能加载,与 Heretic 的加载栈不兼容。

所以需要在 Hugging Face Hub 上下载模型safetensors格式文件

这里我要制作的模型为 Qwen/Qwen3.5-0.8B ，如果模型在 Hugging Face ，则可直接传入仓库地址， heretic 会自动下载模型 safetensors

环境修复:把 PyTorch 从 CPU 版换成 CUDA 版

跑 uv run heretic --model Qwen/Qwen3.5-0.8B ... 第一次尝试:

GPU 被忽略了。这不是驱动问题,而是 PyTorch 装的是 CPU 版。

调查锁文件

锁文件把 torch 钉到 2.14.1+cpu(CPU-only 构建)。

调查 pyproject.toml

pyproject 把 torch 强制绑到 PyTorch 官方 CPU index(为了 CI 避免下载巨大 CUDA 包)。这个设计默认假设了 CPU 环境,对有 GPU 的工作站不友好。注释里也写明可以由 uv --index pytorch=<url> 覆盖。

所以最干净的方案是让 torch 直接走 PyPI 默认源,而不是 PyTorch 专用的 cu-index。
